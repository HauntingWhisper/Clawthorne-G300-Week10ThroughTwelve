 I was so worried that I was going to fumble this project, but ya boy pulled through at the end, two days to spare and ended up getting all my programming in.
I did everything in my power to not make it feel like an empty room tech demo, and personally think the game feels cohesive and well thought out. From the item placements, the room layouts, I even made personal music for the level and the main menu screen. I will say the style of items in the house aren't the most cohesive but that is more due to the fact im working with free assets and they can befairly limiting.

For User Interface, I have all the text boxes, I still have the inventory and theres the UI
